# Bundled Font Source

This directory contains the font files from `dolbydu/font` at the `master` branch:

https://github.com/dolbydu/font

The original repository did not expose a standard `LICENSE`, `COPYING`, or `NOTICE` file in its repository tree when this package was built. The files are included in this program package at the request and authorization of the program maintainer. Downstream distributors should retain this notice and independently confirm redistribution rights for the specific font files.

The `matplotlib-compatible` subdirectory contains copies of `Kaiti.ttf` and `Microsoft Yahei.ttf` with only the digital-signature table removed so that the bundled Matplotlib/FreeType runtime can read them. The original files remain in their source directories.
