# 真题解析内容质量要求

本文档只规定“解析内容本身”的质量要求，不规定版式、题型排版结构、教材页码定位、页码映射或 Word 样式。

## 1. 总原则

1. 解析必须服务于本题作答，不能写成泛泛的知识点讲义。
2. 答案、解析、公式、符号、单位、正负号、条件判断必须前后一致。
3. 解析应简洁但完整，保留得出答案所必需的依据、推理和关键步骤。
4. 不得编造题干条件、教材结论、实验现象、计算数据或隐藏前提。
5. 题干信息不足以唯一判断时，必须说明限制条件或不确定性，不得强行写成确定结论。
6. 正式产物不得出现制作过程说明、工具限制说明、测试说明、模型说明或“待确认”式正文。
7. 内容表达应接近考研答案册，明确、规范、直接，不使用聊天式表达。

## 2. 答案与解析一致性

1. 答案字段和解析结论必须一致。
2. 选择题不得出现答案为 A、解析却支持 B 的情况。
3. 判断题不得出现答案写“正确”、解析却说明命题不成立的情况。
4. 计算题最终答案必须与前文关系式、代入式和结果一致。
5. 若题目存在多种符号约定，必须在解析中说明采用的约定，并保持全文一致。
6. 不得只给最终答案而没有必要解释，除非题目本身只要求极短判断且无需展开。

## 3. 准确性要求

1. 概念定义必须准确，不得把相近概念混用。
2. 物理量、化学量、高分子参数、晶体学符号等必须符合学科常用含义和本题语境。
3. 公式使用必须满足适用条件，不能把特殊条件下成立的公式当成普遍结论。
4. 计算过程中的量纲、单位换算和数量级必须可复核。
5. 正负号约定必须明确，尤其是热、功、电化学、电池反应方向、自由能变化等内容。
6. 标准态、平衡态、可逆过程、理想气体、稀溶液、无限稀释等条件不能省略或误用。
7. 不得把题目没有给出的“默认状态”“默认过程”“默认浓度”“默认理想性”直接当成已知条件。

## 4. 题型内容要求

### 4.1 选择题

1. 必须说明为什么选该选项。
2. 对干扰项明显有辨析价值时，应说明错误原因或不成立条件。
3. 不得只写“根据定义可知选 A”这类空泛句。
4. 若选项差异来自条件、符号、单位、适用范围或概念边界，解析必须点明差异。
5. 若题干条件不足以排除某些选项，必须说明题干不足，不能强行排除。

### 4.2 判断题

1. 必须说明命题成立或不成立的关键依据。
2. 对“总是、一定、只能、任意、所有”等绝对化表述，应检查适用范围。
3. 若命题在特定条件下成立，应写明条件；若题干未给条件，应指出不能无条件成立。
4. 不得只写“正确”或“错误”后简单重复题干。

### 4.3 填空题

1. 答案应直接、规范，避免多余解释影响判分。
2. 解析应说明填入该答案的关键依据。
3. 若填空涉及符号、单位、上下标或方向，应写清楚规范形式。
4. 多空题必须逐空对应，不能合并成模糊说明。

### 4.4 简答题

1. 回答应按要点组织，覆盖题目要求的全部问点。
2. 每个要点应有明确结论，不写空泛套话。
3. 概念类题目应说明定义、适用条件和易混边界。
4. 机理类题目应说明因果链条，不能只罗列现象。
5. 比较类题目应明确比较对象、比较维度和结论。

### 4.5 计算题

1. 必须给出关键关系式。
2. 必须给出代入逻辑，不能只写“代入得”后直接给结果。
3. 必须给出结果和单位。
4. 涉及多个小问时，应保持变量定义和符号约定一致。
5. 中间结果影响后续计算时，应保留必要有效数字。
6. 最终答案应与题目要求的单位、形式和精度匹配。
7. 必须指出本题真正容易错的地方，例如符号约定、过程条件、单位换算、公式适用条件、对数底、标准态或反应计量数。
8. 注意事项必须针对本题，不能多题复用模板句。

### 4.6 图题和图形分析题

1. 解析必须说明图中关键信息如何支撑答案。
2. 坐标轴、曲线趋势、交点、斜率、峰位、相区、晶面/晶向等图形要素应解释清楚。
3. 不得只描述“由图可知”，必须说明由图中哪一特征可知。
4. 若需要重绘图，图中标注必须与解析使用的符号和术语一致。
5. 图形结论不能超出图中信息和题干条件。

## 5. 各题型解析部分写法要求

本节规定“解析：”部分应写什么。解析部分不是题干复述，也不是知识点堆砌，必须解释本题答案如何得到。

### 5.1 选择题解析部分

选择题解析部分必须包含：

1. 本题考查的核心判断点。
2. 正确选项成立的直接原因。
3. 必要时说明题干条件如何触发该判断。
4. 对容易混淆或明显错误的选项进行排除。
5. 最后回到选项结论，明确“故选 X”。

合格解析应做到：

1. 不是只写定义，而是把定义和本题选项对应起来。
2. 排除错误选项时，应说明错误在概念、条件、方向、单位、符号、适用范围还是计算结果。
3. 若四个选项都很接近，应逐项或分类排除。
4. 若只有一个选项明显正确，也至少说明该选项为什么满足题干条件。

不合格写法包括：

1. “根据教材可知，选 A。”
2. “A 正确，其他错误。”
3. “本题考查某概念。”但没有说明选项判断。
4. 只复述题干或选项文字。

### 5.2 判断题解析部分

判断题解析部分必须包含：

1. 命题中的关键限定词或关键条件。
2. 判断为正确或错误的核心依据。
3. 若命题错误，应指出错在何处，并给出正确说法。
4. 若命题在特定条件下才成立，应说明该条件。

合格解析应做到：

1. 对“总是、一定、只能、任意、所有、均、必然”等绝对化表述进行核验。
2. 对概念边界进行说明，例如平衡/非平衡、理想/非理想、可逆/不可逆、标准态/非标准态。
3. 结尾应与判断结果一致。

不合格写法包括：

1. “该说法正确。”
2. “该说法错误。”
3. “根据定义判断。”但没有给出定义和命题的关系。
4. 对错误命题只说“不全面”，但不说明缺少什么条件。

### 5.3 填空题解析部分

填空题解析部分必须包含：

1. 空格答案来自哪个概念、公式、定义、分类或计算关系。
2. 多空题应逐空说明对应关系。
3. 若答案有单位、上下标、方向、正负号或符号形式，应说明为什么采用该形式。
4. 若题目可由公式推出，应给出关键推导关系，不得只写结论。

合格解析应做到：

1. 解析简短，但必须能解释为什么填这个答案。
2. 对同义答案或等价写法，应说明是否可接受。
3. 若空格要求专业术语，应使用规范术语，不用口语化替代。

不合格写法包括：

1. “根据概念填空。”
2. “答案如上。”
3. 多空题只整体解释，不对应每一空。
4. 对带单位或符号的答案不说明单位或符号来源。

### 5.4 名词解释题解析部分

名词解释题解析部分必须包含：

1. 该名词的核心定义。
2. 定义中的关键限定条件。
3. 必要时补充物理意义、化学意义、适用范围或常见混淆点。
4. 若题目要求举例，应给出准确例子；未要求时不必过度扩展。

合格解析应做到：

1. 定义完整，不漏主语、对象、条件和结果。
2. 语言规范，避免用近义词模糊替代专业术语。
3. 对容易混淆的概念，应点明差异。

不合格写法包括：

1. 只写一个近义词或口语解释。
2. 用例子替代定义。
3. 定义过宽或过窄，导致概念范围错误。
4. 写成教材长段背景，但没有核心定义。

### 5.5 简答题解析部分

简答题解析部分必须包含：

1. 对题目问点的逐项回应。
2. 每个要点的明确结论。
3. 支撑该结论的核心理由。
4. 若题目要求比较、说明原因、分析影响因素，应分别给出比较维度、因果链或因素作用方向。

合格解析应做到：

1. 按题目问法组织，不遗漏小问。
2. 要点之间逻辑清楚，不互相重复。
3. 关键术语准确，必要条件不省略。
4. 结论先行，解释随后展开。

不合格写法包括：

1. 只罗列相关知识点，未回答题目。
2. 只写背景介绍，没有明确结论。
3. 多个问点混写，无法对应判分点。
4. 使用“影响较大、关系密切、比较复杂”等空泛表述。

### 5.6 论述题解析部分

论述题解析部分必须包含：

1. 总体结论或中心观点。
2. 分层论述要点。
3. 每一层要点的依据、机制或推理。
4. 必要时给出公式、图示、分类或对比关系。
5. 结尾回扣题目要求，不写无关扩展。

合格解析应做到：

1. 有清晰层次，不能写成散乱段落。
2. 论述深度应高于简答题，但不得写成泛泛教材摘抄。
3. 对机制、过程、影响因素、适用范围进行展开。
4. 若题目要求“分析”，必须体现因果或逻辑链。

不合格写法包括：

1. 只堆概念名词。
2. 没有中心结论。
3. 只写一段笼统背景。
4. 与题目主题相关但不能直接构成答案的扩展内容过多。

### 5.7 计算题解析部分

计算题解析部分必须包含：

1. 已知量和要求量之间的关系说明。
2. 使用的关系式及其适用条件。
3. 代入式或代入逻辑。
4. 计算结果、单位和必要的有效数字。
5. 多小问之间的结果传递关系。
6. 最终答案汇总。

合格解析应做到：

1. 每个公式都能解释为什么用于本题。
2. 关键中间量不能省略到无法复核。
3. 单位换算、符号约定、反应计量数、正负号方向必须清楚。
4. 如果使用近似，应说明近似前提。
5. 若题目包含多个过程，应分别说明各过程条件，不能混用公式。

不合格写法包括：

1. “代入公式得结果。”
2. 只有公式和最终数值，没有说明变量含义。
3. 缺单位或单位前后不一致。
4. 前文符号约定和最终答案符号冲突。
5. 漏掉小问或把多个小问结果混在一起。

### 5.8 证明题和推导题解析部分

证明题和推导题解析部分必须包含：

1. 推导起点。
2. 使用的基本关系、定义式或假设条件。
3. 关键变形步骤。
4. 每个等价变形的条件。
5. 推导终点与题目要求式的对应关系。

合格解析应做到：

1. 不跳过关键变形。
2. 明确常量条件、偏导条件、积分上下限、边界条件等。
3. 若证明依赖近似或理想条件，应写明。
4. 结尾应说明“即得”或“故证明”的对象。

不合格写法包括：

1. 直接写出目标公式。
2. 用“整理可得”跳过核心步骤。
3. 偏导、积分、下标条件不清。
4. 推导式与题目要求式不一致。

### 5.9 图题和图形分析题解析部分

图题解析部分必须包含：

1. 图中用于判断的关键视觉信息。
2. 该视觉信息对应的物理、化学、材料或数学含义。
3. 由图到答案的推理过程。
4. 必要时说明坐标轴、曲线、峰、相区、斜率、截距、晶面/晶向、标注符号的含义。

合格解析应做到：

1. 明确指出“看图”的具体依据。
2. 图形结论与题干条件一致。
3. 若图中多个特征共同决定答案，应逐一说明。
4. 若需要结合公式或概念判断，应把图形信息和公式/概念连接起来。

不合格写法包括：

1. “由图可知。”
2. 只描述图形外观，不解释专业含义。
3. 图中没有的信息被写入解析。
4. 坐标轴或标注含义误读。

### 5.10 综合题解析部分

综合题解析部分必须包含：

1. 题目涉及的多个知识点拆分。
2. 各知识点之间的逻辑关系。
3. 分步作答过程。
4. 每一步的结论和依据。
5. 最终答案汇总。

合格解析应做到：

1. 先拆题，再逐步解决。
2. 明确每一步服务于哪个小问或哪个结论。
3. 不同知识点之间衔接自然，不机械堆叠。
4. 若存在多种解法，应选择最适合考试答案册的一种，不展开无关解法。

不合格写法包括：

1. 多个知识点混写，无法看出解题路径。
2. 每一步都正确但没有汇总答案。
3. 只给最终结论，没有分解过程。
4. 引入与本题无关的高级知识导致答案偏离考试要求。

## 6. 公式和符号内容要求

1. 承担推导、判据、定义、比较或计算功能的表达式必须作为公式处理。
2. 公式不能只出现而没有解释；关键公式应说明用途和适用条件。
3. 条件下标必须作用于完整表达式，不能因书写或转换导致语义挂错。
4. 标准态符号、上下标、函数名、微分符号、偏导条件、平均量符号、单位格式等必须统一。
5. 教材或题干已有固定符号时，应沿用该写法，不得按模型习惯替换为看似等价的符号。
6. 简单化学式可以使用稳定 Unicode，但只要参与推导、比较、定义或计算，就应进入公式对象。
7. 公式中的变量应在必要处说明含义，特别是题目容易混淆的变量。
8. 不得把线性 LaTeX、Unicode 拼接式公式或截图公式当作正式公式内容。

## 7. 单位、有效数字和量纲

1. 数值结果必须带单位，除非该量本身无量纲或题目明确不要求。
2. 单位换算必须可追溯，关键换算不能省略。
3. 同一题内单位体系应一致，不得前后混用造成量纲错误。
4. 结果数量级应合理；若数量级异常，应检查单位和公式。
5. 有效数字应与题目给定数据和常见答案册习惯相协调。
6. 对数、指数、百分数、摩尔分数、质量分数等形式必须区分清楚。

## 8. 推理深度

1. 解析必须有从题干到答案的推理链。
2. 推理链应包含“题干条件 -> 使用依据 -> 判断或计算 -> 结论”。
3. 不能用“显然”“易得”“根据常识”替代关键推理。
4. 若一步推理依赖隐含前提，应把前提说出。
5. 对考试高频易错点，应优先解释为什么容易错，而不是堆砌背景知识。
6. 不得为了显得完整而写与本题无关的教材段落。

## 9. 不确定性和缺证处理

1. 当题干条件不足时，应明确写出“不足以唯一判断”的原因。
2. 当多个答案在不同约定下可能成立时，应说明采用哪一约定。
3. 当缺少必要数据时，不得补造数据进行计算。
4. 当无法确认某个专业写法时，不得强行给出确定的符号规范。
5. 正式答案中不得保留“模型无法判断”“等待用户补充”“本次测试允许”等过程性文字。

## 10. 易错点和注意事项

1. 易错点必须对应本题真实风险。
2. 注意事项必须能帮助避免本题出错。
3. 不得多题复用同一句模板，例如“注意单位换算”“注意公式适用条件”而不说明具体单位或条件。
4. 计算题应优先提示符号约定、公式适用条件、单位换算、计量数、边界条件等。
5. 概念题应优先提示概念混淆、适用范围、绝对化表述等。
6. 图题应优先提示坐标含义、曲线方向、相区边界、峰位归属等。

## 11. 禁止内容

1. 禁止编造教材依据、题干条件、数值、实验事实或图形信息。
2. 禁止把不确定结论写成确定结论。
3. 禁止出现与答案无关的长篇背景介绍。
4. 禁止输出制作过程语言，例如“本题需要人工复核”“由于工具限制”“本次测试阶段”。
5. 禁止把公式写在普通正文中代替公式对象。
6. 禁止只给答案不解释关键依据。
7. 禁止选项解析和最终答案互相矛盾。
8. 禁止计算题跳步到无法复核。
9. 禁止多题复用空泛易错点或注意事项。
10. 禁止使用聊天式语气、营销式表述或论文式冗长铺垫。

## 12. 内容审计建议

平台应把解析内容质量拆成可机器验证项和有界 AI 复检项；后者只能告警、降级或触发有上限的自动修复。

程序可优先检查：

1. 是否缺答案、缺解析、缺公式对象、缺计算结果。
2. 选择题是否只有选项而无解释。
3. 判断题是否只有“正确/错误”而无依据。
4. 计算题是否缺关系式、代入式、结果、单位、最终答案。
5. text segment 中是否存在公式样式内容。
6. 答案字段是否含公式、单位计算式或上下标。
7. 易错点和注意事项是否为空或高度重复。
8. 是否出现过程性文字、测试文字、工具限制文字。
9. 最终答案是否与答案字段或解析结论明显冲突。

人工或模型复核应重点判断：

1. 答案是否真正正确。
2. 推理链是否成立。
3. 公式适用条件是否满足。
4. 符号、单位、正负号是否符合本题语境。
5. 干扰项排除是否准确。
6. 易错点是否确实有价值。
7. 图形解释是否与图中信息一致。
8. 不确定性处理是否合理。

## 13. 平台生成侧要求

1. 模型只负责生成结构化内容草稿，不能直接决定最终 Word 形态。
2. 模型输出必须先通过内容与结构审计，再进入 Word 生成。
3. 若结构化内容审计失败，应回到模型生成、检索输入或人工编辑阶段修复。
4. 若结构化内容通过但 Word 审计失败，应定位为 Word 生成、公式转换或样式写入问题。
5. 若 Word 审计通过但渲染失败，应定位为 Word 渲染、字体、公式兼容或图片问题。
