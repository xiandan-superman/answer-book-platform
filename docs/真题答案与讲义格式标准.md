# 真题答案与讲义格式标准

> 本标准仅从《3、真题答案-金属方向-20260224版》和《北航讲义》两个最终产出样本中提取。两个任务分别保留自己的标题和内容层级，不将两者强行统一。未在样本中形成稳定用法的偶发格式不纳入标准。

## 1. 真题答案任务格式标准

### 1.1 页面与全局设置

| 格式对象 | 标准值 |
|---|---|
| 页面尺寸 | JIS B5，18.2 cm × 25.7 cm |
| 页面方向 | 纵向 |
| 上、下、左、右页边距 | 均为 1.7 cm |
| 页眉距页面顶端 | 1.3 cm |
| 页脚距页面底端 | 1.3 cm |
| 正文中文字体 | 宋体 |
| 正文英文、数字字体 | Times New Roman |
| 正文字号 | 11 pt |
| 正文对齐 | 两端对齐 |
| 正文行距 | 1.5 倍 |
| 正文首行缩进 | 10 pt |
| 正文段前、段后 | 0 pt |
| 文字颜色 | 黑色 |

### 1.2 标题与结构层级

| 内容角色 | 中文字体 | 英文、数字字体 | 字号 | 字形 | 对齐与段落规则 |
|---|---|---|---:|---|---|
| 前置说明总标题，如“复习规划及本书使用指南” | 宋体 | Times New Roman | 22 pt | 加粗 | 居中，不缩进 |
| 前置说明分节标题，如“一、801材料综合内容简介” | 宋体 | Times New Roman | 12 pt | 加粗 | 左对齐，不缩进 |
| 学校名称行 | 黑体 | Times New Roman | 18 pt | 加粗 | 居中，1.25 倍行距 |
| 年份考试标题，如“1999年硕士学位研究生入学考试答案” | 黑体 | Times New Roman | 18 pt | 加粗 | 居中，1.25 倍行距；与下一段同页 |
| 科目代码与科目名称 | 继承学校名称行 | 继承学校名称行 | 12 pt | 常规 | 居中 |
| 考生注意/说明 | 黑体 | Times New Roman | 12 pt | 加粗 | 两端对齐，1.25 倍行距，不缩进 |
| 大题标题，如“一、填空题” | 宋体 | Times New Roman | 11.5 pt | 加粗 | 左对齐 |
| 居中的试卷部分标题 | 黑体 | Times New Roman | 12 pt | 加粗 | 居中，不缩进 |
| 普通题干、答案、解析 | 宋体 | Times New Roman | 11 pt | 常规 | 按正文格式 |

### 1.3 公式、图、表与页眉页脚

| 格式对象 | 标准值 |
|---|---|
| 公式对象 | 使用 Word 原生公式格式，不以普通文字或图片模拟 |
| 公式字体 | Cambria Math |
| 行内公式 | 随正文排列，字号与正文协调 |
| 独立公式 | 单独成段；根据原答案推导结构左对齐或居中，不使用空格强行定位 |
| 图片段落 | 使用“图”样式，居中，不缩进 |
| 图片比例 | 保持原始宽高比，不拉伸 |
| 表格正文 | 中文宋体、英文数字 Times New Roman，11 pt |
| 表格段落 | 使用“表”样式；水平居中，单倍行距 |
| 表格行高 | 自动适应内容，不固定为可能截字的高度 |
| 页眉内容 | “航研学考研 丨 专注北航考研 丨 材料考研群954467835” |
| 页眉格式 | 黑体 12 pt，加粗，居中；下方保留横线 |
| 页脚宣传语 | 华文新魏，继承页脚 9 pt，居中 |
| 页码 | 页脚居中，阿拉伯数字连续编号，9 pt |

## 2. 讲义任务格式标准

### 2.1 页面与全局设置

| 格式对象 | 标准值 |
|---|---|
| 页面尺寸 | JIS B5，18.2 cm × 25.7 cm |
| 页面方向 | 纵向 |
| 上、下、左、右页边距 | 均为 1.7 cm |
| 页眉距页面顶端 | 1.3 cm |

### 2.2 标题与知识层级

| 内容角色 | 中文字体 | 英文、数字字体 | 字号 | 字形 | 对齐与段落规则 |
|---|---|---|---:|---|---|
| 前置说明总标题，如“复习规划及本书使用指南” | 宋体 | Times New Roman | 22 pt | 加粗 | 居中，不缩进 |
| 前置说明分节标题 | 宋体 | Times New Roman | 12 pt | 加粗 | 左对齐，不缩进 |
| 一级标题，如“801材料综合考试大纲”及章标题 | 继承正文中英文字体 | Times New Roman | 22 pt | 加粗 | 居中，不缩进 |
| 二级标题 | 继承正文中英文字体 | Times New Roman | 14 pt | 加粗 | 居中，不缩进 |
| 三级标题 | 继承正文中英文字体 | Times New Roman | 12 pt | 常规 | 两端对齐，不缩进 |
| 节内重点小标题 | 宋体 | Times New Roman | 12 pt | 加粗 | 按内容需要左对齐或居中，不缩进 |
| 发布日期等标题辅助信息 | 宋体 | Times New Roman | 11 pt | 加粗 | 居中 |
| 正文知识讲解 | 宋体 | Times New Roman | 11 pt | 常规 | 两端对齐，1.5 倍行距，首行缩进 22.1 pt |
| 注释内容 | 继承正文格式 | 继承正文格式 | 11 pt | 常规 | 使用“注”样式，首行缩进 5 pt |

### 2.3 公式、图、表与页眉页脚

| 格式对象 | 标准值 |
|---|---|
| 公式对象 | 使用 Word 原生公式格式，不以普通文字或图片模拟 |
| 公式字体 | Cambria Math |
| 行内公式 | 随正文排列，字号与正文协调 |
| 独立公式 | 单独成段；按讲义原有推导结构排列，不使用连续空格强行定位 |
| 公式编号 | 位于公式同行右侧，沿用“（章.节.序号a/b）”形式 |
| 图片段落 | 使用“图”样式，居中，不缩进 |
| 图片比例 | 保持原始宽高比，不拉伸 |
| 图号 | 沿用“图（章.节.序号a/b）”或样本中对应章节编号形式 |
| 表格正文 | 中文宋体、英文数字 Times New Roman，11 pt |
| 表格对齐 | 短内容居中；公式或较长说明按表内结构对齐 |
| 表格行高 | 自动适应内容，不固定为可能截字的高度 |
| 页眉内容 | “航研学考研 丨 专注北航考研 丨 材料考研群954467835” |
| 页眉格式 | 黑体 12 pt，加粗，居中；下方保留横线 |
| 页脚宣传语 | 华文新魏 10.5 pt，深灰色（#404040），居中 |
| 页码 | 页脚居中，阿拉伯数字连续编号，9 pt |

## 3. 两类任务公共格式标准

| 格式对象 | 两类任务共同标准 |
|---|---|
| 页面尺寸 | JIS B5，18.2 cm × 25.7 cm |
| 页面方向 | 纵向 |
| 页边距 | 上、下、左、右均为 1.7 cm |
| 页眉、页脚距离 | 均为 1.3 cm |
| 正文中文字体 | 宋体 |
| 正文英文、数字字体 | Times New Roman |
| 正文字号 | 11 pt |
| 正文行距 | 1.5 倍 |
| 正文对齐 | 两端对齐 |
| 正文段前、段后 | 0 pt |
| 正文颜色 | 黑色 |
| 前置说明总标题 | 宋体 22 pt、加粗、居中 |
| 前置说明分节标题 | 宋体 12 pt、加粗、左对齐 |
| 数学公式 | Word 原生公式对象，Cambria Math |
| 图片 | 独立段落居中，保持宽高比 |
| 表格 | 字体与正文一致；行高自动适应内容 |
| 页眉 | 黑体 12 pt、加粗、居中，保留横线 |
| 页码 | 页脚居中、阿拉伯数字连续编号、9 pt |
| 中文与英文混排 | 中文使用宋体；英文字母、阿拉伯数字使用 Times New Roman；公式除外 |
| 格式控制方式 | 标题、正文、注释、图、表必须通过对应 Word 样式控制，不依赖空格、Tab 或连续空段落模拟版式 |
| 分页规则 | 标题不得孤立在页尾；标题与首段、图片与对应说明、表题与表格应保持同页 |
| 图表完整性 | 不允许图片拉伸、表格截字、公式裁切或内容超出版心 |
