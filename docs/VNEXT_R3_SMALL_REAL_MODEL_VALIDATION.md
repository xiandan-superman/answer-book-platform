# VNext-R3 小额真实模型验证

> 日期：2026-08-20  
> 版本：`8.26-vnext.r3`  
> 范围：只跑 P2-02、P2-04、P2-05；未启动 P2-01～P2-05 全量矩阵或整卷付费测试

## 1. 结论

R3 的流程边界得到真实任务验证：没有答案时阻断；图和 Word 完整但内容仍存疑时输出待复核候选；模型计算错误不会被包装成正式答案。P2-04 的确定性 XRD 路线成功，P2-05 的五题覆盖、图件交付和 Word 渲染成功。

R3 仍不是“所有任务都已证明正确”的发布结论。P2-02 因服务商 SSL EOF 没有获得最终科学答案，属于未验证；P2-05 模型答案存在可复现的数值矛盾，程序正确检出并阻止正式交付。当前更准确的定位是：**最值得继续验证的独立候选版，流程可信度明显提高，但模型学科质量仍需样本扩展。**

## 3. 测试后通用修复

1. 成功的模型备用图会从活动规格中淘汰同题已失败的主图，避免“有效图已存在但整题仍阻断”。
2. XRD 渲染支持按状态分行对比，基础峰使用实线、超结构峰使用虚线，统一黑白表达；caption 不再自动重复为图内标题。
3. 断点恢复只在题目生成提示、图像模型、尺寸和图片完整性均一致时复用备用图；任一不一致都重新生成。该合同避免错误缓存，也避免同一图重复付费。
4. 以上逻辑位于通用图件生命周期或 `materials.figures` 能力包，没有写入 P2 题目的答案、数值或样例 ID。

## 5. 使用者与程序的剩余风险

- 使用者仍会感知 P2-04/P2-05 的 2.5～6 分钟等待；当前优先级是结果可信和可恢复，而不是单纯压缩到最短耗时。
- P2-05 的主要剩余问题来自模型科学推理：程序识别出了矛盾，但一次修复没有生成可机器验证的正确答案。后续应比较“只重做风险题”与“升级高能力模型一次”的质量收益和增量成本。
- P2-02 本轮只能说明网络失败不会导致假交付，不能用于评价 R3 对热力学歧义题的最终答案质量。
- P2-04 测试后的黑白双行 XRD 改进只做了离线渲染和全库回归，尚未再产生付费视觉 QA 结果。
- 全量质量门通过：`908 passed, 7 skipped, 1 deselected`，`ruff`、`mypy`、公式、项目完整性和 63% 覆盖率门均通过。

## 6. 下一步建议

暂不扩大整卷付费测试。下一轮只需补两项小额验证：P2-02 在服务恢复后重跑一次；P2-05 仅针对失败计算题做“原模型定向重做 vs 高能力模型一次”对照。通过标准是科学正确、状态分层一致、无重复生图，并报告单位正式交付成本。
