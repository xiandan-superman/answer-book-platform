# 真题录入模板（全题型）

> 用途：把本模板复制到 Word 中填写并保存为 `.docx`，再上传到平台。模板按当前程序的抽题规则设计，便于题目切分、题型确认、模型结构化答案生成和最终答案册整理。

## 一、填写规则

1. 大题标题使用中文序号加顿号：`一、选择题`、`二、判断题`、`三、填空题`。
2. 小题编号使用阿拉伯数字加顿号：`1、`、`2、`、`3、`。不要使用自动编号生成看不见的编号。
3. 多小问使用独立段落：`（1）`、`（2）`、`（3）`。不要把多个小问塞进同一段。
4. 题干中的表格请使用 Word 真表格，程序会转成结构化表格附件。
5. 题干中的图片请直接插入 Word 文档，并在题干文字中写明“如图”“下图”“画出”“绘制”等提示。
6. 公式尽量使用 Word 公式对象；如果只能输入纯文本，保持符号完整，不要把关键公式拆散到多个段落。
7. 名词解释题使用独立“名词解释”题型；证明题、推导题、论述题、实验题、综合题在当前程序里按“简答题”大类处理；如果包含计算或作图小问，请在小问题干中明确写“计算”“画出”“绘制”。
8. 选做题建议明确写“选做其一”并把每个选项题作为小问列出；后续在题型确认弹窗里可人工校正。

## 二、程序题型映射

| 模板题型 | 当前程序识别大类 | 建议写法 |
|---|---|---|
| 选择题 | 选择题 | 大题标题含“选择题”，每题 `1、` 开头，选项用 A. B. C. D. |
| 判断题 / 正误题 | 判断题 | 大题标题含“判断题”或“正误题”，题干写清判断命题。 |
| 填空题 | 填空题 | 大题标题含“填空题”，空格建议写 `____` 或 `（  ）`。 |
| 名词解释题 | 名词解释 | 大题标题可写“名词解释题”，最终结构为“教材依据、答案”。 |
| 简答题 / 问答题 | 简答题 | 大题标题含“简答题”或“问答题”，问点逐条写清。 |
| 论述题 | 简答题 | 大题标题可写“论述题”，建议在题干中写“从……方面论述”。 |
| 证明题 / 推导题 | 简答题 | 大题标题可写“证明题”或“推导题”，题干写明起点和目标式。 |
| 实验题 | 简答题 | 大题标题可写“实验题”，建议按原理、步骤、现象、结论拆问。 |
| 计算题 | 计算题 | 大题标题含“计算题”，题干写全已知量、单位、要求量。 |
| 作图题 / 图示题 | 作图题 | 大题标题含“作图题”“画图题”“图示题”，题干写明图形元素、坐标、标注。 |
| 图形分析题 | 作图题或简答题 | 若要求画图，用“作图题”；若只分析已有图，可放“简答题”。 |
| 综合题 | 简答题 / 混合题 | 建议用多小问拆成计算、作图、简答等具体小问。 |

## 三、推荐真题正文模板（最稳结构）

# 【学校/学院】【科目代码】【科目名称】真题

考试年份：20XX 年

适用方向：【可选】

说明：本文件用于平台解析。正式上传前请删除本说明行。

## 一、选择题

1、【题干】下列关于【概念/规律】的说法，正确的是（  ）。

A. 【选项 A】

B. 【选项 B】

C. 【选项 C】

D. 【选项 D】

2、【题干】若【条件】，则【问题】（  ）。

A. 【选项 A】

B. 【选项 B】

C. 【选项 C】

D. 【选项 D】

## 二、判断题

1、【判断命题】在【条件】下，【说法】。

2、【判断命题】当【变量/条件】变化时，【结论】一定成立。

## 三、填空题

1、【题干】根据【定义/规律/公式】，____ 称为【概念】，其单位为 ____。

2、【题干】在【条件】下，【量】与【量】的关系为 ____，因此【结论】为 ____。

## 四、简答题

说明：问答题、论述题、证明题、推导题、实验题、综合分析题，在当前程序里都建议放在“简答题”大题下；名词解释题可以单独使用“名词解释题”大题。如果某小问是计算或作图，请在小问题干中明确写“计算”或“画出/绘制”。

1、【名词解释题】解释【名词 1】。

2、【名词解释题】解释【名词 2】，并说明其适用条件。

3、【简答题】简述【概念/现象/过程】的主要特征，并说明其原因。

4、【比较题】比较【对象 A】与【对象 B】在【维度 1】、【维度 2】方面的区别。

5、【分析题】分析【因素 1】、【因素 2】对【结果】的影响。

6、【论述题】论述【主题】。要求从【基本原理】、【影响因素】、【实际意义】三个方面回答。

7、【证明题】由【已知关系/定义式】出发，证明：

【目标式】

8、【推导题】在【假设条件】下，推导【目标关系式】，并说明各符号含义。

9、【实验题】某实验用于测定【对象/参数】。

（1）写出实验原理。

（2）说明主要实验步骤。

（3）若出现【现象/误差】，分析可能原因。

（4）说明如何根据实验数据得到【结论/参数】。

10、【综合分析题】围绕【综合主题】，回答下列问题。

（1）解释【基础概念】。

（2）说明【条件】对【结果】的影响。

（3）结合（1）至（2）分析【综合结论】。

## 五、计算题

1、已知【物理量 1】为【数值+单位】，【物理量 2】为【数值+单位】。求【要求量】。

（1）写出所用关系式，并说明适用条件。

（2）计算【中间量】。

（3）计算【最终量】，结果保留【有效数字】并注明单位。

2、【多步计算题题干】。

（1）根据题干条件求【第一问要求量】。

（2）利用（1）的结果继续求【第二问要求量】。

（3）判断【结果/方向/自发性/稳定性】，并说明依据。

3、【附表计算题】根据下表数据，计算【要求量】并分析【变化趋势】。

| 项目 | 数值 | 单位 | 说明 |
|---|---:|---|---|
| 【量 1】 | 【数值】 | 【单位】 | 【说明】 |
| 【量 2】 | 【数值】 | 【单位】 | 【说明】 |

（1）写出计算关系式。

（2）代入表中数据计算。

（3）说明结果的物理意义。

## 六、作图题

1、根据【条件】，画出【图名/示意图】，并标出【坐标轴/关键点/曲线/区域/方向】。

2、在下图基础上，标出【相区/峰位/晶面/晶向/斜率/截距】并说明含义。

【此处插入图片】

3、【图形分析题】观察下图，回答问题。

【此处插入图片】

（1）指出图中【关键特征】。

（2）说明该特征对应的【物理/化学/材料】意义。

（3）根据图中信息判断【结论】。

## 四、上传前自检清单

- [ ] 每个大题标题都形如 `一、选择题`。
- [ ] 每个小题都形如 `1、题干`。
- [ ] 多小问都单独成段，使用 `（1）`、`（2）`。
- [ ] 题干没有只写“见图”而缺少文字说明。
- [ ] 表格为 Word 表格，不是截图。
- [ ] 计算题包含已知量、单位、要求量。
- [ ] 作图题明确需要画什么、标什么。
- [ ] 综合题拆成清晰小问。
- [ ] 上传前删除模板说明、占位符和不用的题型章节。
