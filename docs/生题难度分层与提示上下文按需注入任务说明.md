# 生题难度分层与提示上下文按需注入任务说明

## 项目范围

`/Users/ljj/Documents/分析多模态问题/answer_book_platform_v1_v6.8_material_figure_schema_flow_standalone`

## 目标一：让基础、进阶、挑战具有明确且通用的差异

当前难度主要是标签和题量分配，模型没有收到明确的难度实现方式，生成结果的层级差异不明显。

### 实现要求

1. 不使用“固定推理步数”作为所有学科和题型的统一硬规则。
2. 蓝图应根据题型和考查内容，从下列难度调节维度中选择适用项：
   - 条件直接程度；
   - 条件识别或转换要求；
   - 方法选择与组合要求；
   - 知识综合与迁移程度；
   - 隐含关系识别；
   - 正向、逆向、比较、评价或优化任务；
   - 提示和解题支架程度；
   - 计算、论证或数据处理负担。
3. 三个难度层级采用以下通用方向：
   - 基础：条件较直接、方法较明确、支架较充分；
   - 进阶：存在方法选择、条件转换或知识组合；
   - 挑战：存在明显的综合迁移、隐含条件、逆向推理、评价或优化要求。
4. 蓝图每项增加难度设计信息，例如：

```json
{
  "difficulty": "挑战",
  "difficulty_levers": ["隐含条件识别", "逆向推理"],
  "difficulty_rationale": "需要由结果反推初始条件，并组合多个关系完成验证"
}
```

5. `difficulty_levers` 只选择本题真正适用的难度维度，不要求每题覆盖全部维度。
6. 正式生题时必须传入该蓝图项的难度调节方式和依据，并要求题目通过这些方式体现难度。
7. 难度检查重点确认三个层级是否存在实际要求差异；推理步数、计算量和知识点数量只作为参考或预警，不作为统一硬门禁。
8. 当一一对应或逐题变式需要保留原题完整知识点组合时，基础题通过增加提示、减少条件转换等方式降低难度，不得为了降难度删除必考知识点。

## 目标二：所有提示上下文按实际需求注入，减少无关信息

题型只是冗余输入的一种情况。材料分析、蓝图生成和正式生题的每次模型调用，都只应接收完成当前任务真正需要的来源、策略、难度、题型、学科、图文能力、格式和输出要求，避免把其它阶段或其它题目的规则一并发送给模型。

### 实现要求

1. 将提示内容拆分为“通用要求”和“按需模块”。通用要求只保留当前调用必须遵守的最小规则，避免重复描述。
2. 按模型调用阶段注入：
   - 材料分析阶段只提供材料理解、范围识别和分析输出要求，不提供正式生题、答案或导出规则；
   - 蓝图阶段只提供已确认范围、当前策略、难度设计和蓝图输出要求，不提供无关的正式题目字段规则；
   - 正式生题阶段只提供已确认蓝图和本批题目需要的内容要求，不重复整套分析过程和其它阶段说明。
3. 按来源注入：每个正式生题批次只提供蓝图项实际绑定的来源；开关关闭时不提供来源原文；不得无差别传入整套试卷或全部知识材料。
4. 按生成策略注入：整体综合、一一对应、逐题变式、知识点整体和知识点逐项只提供当前选中策略的规则，不同时解释其它策略。
5. 按难度注入：正式生题时只提供该蓝图项的难度层级、`difficulty_levers` 和 `difficulty_rationale`，不重复发送其它难度层级的完整说明。
6. 按题型注入：根据 `question_type` 只提供当前题型要求。填空题不接收选择题选项、作图题图件或计算题步骤等无关规则；其它题型同理。
7. 按内容能力注入：仅当蓝图明确需要公式、表格、图形、图片、材料引用、选项或其它结构时，才注入对应格式、渲染和完整性要求。
8. 按学科注入：化学式、热力学标准态符号等学科专用格式规则，只在相应学科或内容确实涉及这些表达时注入；不得对无关学科统一发送。
9. 按批次和蓝图项注入：混合题型或混合能力批次中，每个蓝图项携带自己的专用约束，批次公共区域只保留真正共同的要求。
10. 按输出任务注入：只提供当前调用需要返回的 JSON 字段和结构，不发送当前阶段不会产出的答案、解析、图件或导出字段。
11. 不得因精简提示删除必要约束。`required_knowledge_points`、必要定义、公式、适用边界、来源开关状态、用户要求和蓝图中的实际设计约束必须保留。
12. 不改变现有题量和策略含义，只优化提示内容的选择、分组和组装方式。

## 验收要求

- 同一知识点生成基础、进阶、挑战题时，蓝图能说明各自采用的难度调节方式，正式题目具有可感知差异。
- 不同题型能够选择不同的难度实现方式，不受固定步骤数限制。
- 分别捕获材料分析、蓝图和正式生题提示，验证每个阶段不存在其它阶段的无关规则。
- 捕获不同生成策略的提示，验证只包含当前策略要求。
- 填空题提示中不存在选择题、作图题等无关要求；其他题型同理。
- 混合题型批次中，每个蓝图项只携带自己的题型、难度和能力要求。
- 未使用公式、表格、图形或图片的题目不接收对应专用要求。
- 无关学科不接收化学、热力学等学科专用格式要求。
- 来源材料关闭时，提示中不包含来源原文；开启时也只包含当前蓝图项需要的来源内容。
- 精简后的提示仍完整包含知识点、必要知识边界、用户要求和蓝图硬约束。
- 保持旧蓝图兼容；缺少难度设计字段时，根据难度、题型和现有设计意图生成合理默认值。
- 只修改相关蓝图、提示组装、校验和测试，不进行无关重构。
- 完成后说明修改文件、实际执行逻辑和测试结果。
