# 服务商能力复核记录（2026-09-12）

## 结论

能力准入必须按“服务商 + 账号指纹 + 模型 + 协议 + 能力”记录，模型名称相同不能跨协议继承结论。完整候选探测可以为当前账号建立有时效的运行时能力，但不能改写所有账号共享的静态能力表。

WawAPI `gpt-5.6-sol` 的本机真实复测结果：

| 协议 | 原生工具调用 | 工具结果回灌 | 回灌图片识别 | 结论 |
| --- | --- | --- | --- | --- |
| `chat_completions` | 通过 | 通过 | 通过 | 登记为主模型工具闭环路线 |
| `responses` | 未完成 | 未完成 | 未完成 | 上游在探测时超时，保持候选/未准入 |

该结果只代表本次实际使用的账号与测试时间点，不是供应商长期 SLA。生产调用不得在两条协议间静默回退。

## 探测覆盖

| 能力 | 探测内容 | 自动频率 | 生产影响 |
| --- | --- | --- | --- |
| 文本 | 固定 JSON 往返 | 5 小时 | 更新精确路线健康状态 |
| 视觉输入 | 随机双色图，提示不泄露答案并校验左右颜色 | 24 小时 | 更新视觉路线健康状态 |
| 工具闭环 | 唯一结构化调用、参数、`call_id`、结果回灌、回灌图片、最终 JSON | 24 小时健康复核 | 完整成功只开放当前账号精确路线，7 天无成功复核自动失效 |
| 生图 | 真实生成文件 | 纯图片供应商首次启动一次，后续手动 | 与文字/工具能力分开记录 |
| 参考图编辑 | 携带真实参考图并生成编辑结果 | 仅手动 | 与从零生图分开记录 |
| 模型目录 | 拉取供应商公开目录并计算候选差异 | 24 小时 | 只记录候选，不自动增删模型 |

## 修复边界

- 工具能力登记同时核对模型与协议，不再由一个通用布尔值放开所有协议。
- 探测代码可在隔离上下文中测试未登记候选；完整通过后只对当前 Key 指纹、模型和协议形成运行时准入，不跨账号、模型或协议继承。
- 已保存 Key 但从未进入运行中心的供应商会在启动后探测一条默认最高覆盖路线；纯图片供应商只在该 Key 首次登记时生成一次测试图，参考图编辑仍保持手动。
- 工具探测失败会立即撤销该路线先前的运行时能力标记；连续 7 天没有成功复核也会失效。人工维护的静态能力登记不会被删除。
- 所有持久化记录不保存 API Key、业务提示词、题目、教材内容或探测图片。
