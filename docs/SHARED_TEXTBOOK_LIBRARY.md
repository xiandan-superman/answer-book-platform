# 共享教材库（Tailscale）

共享教材库用于三人各自在本机运行平台时，复用一份已经验证过的教材和索引。它不是远程共享目录：教材库主机发布不可变 ZIP 版本，客户端校验后下载到自己的 `textbooks/shared/` 和 `cache/textbook_indexes/`。因此客户端建立任务后不依赖教材库主机持续在线。

## 主机配置

1. 在教材库主机本机上传教材并建立索引。
2. 在“教材管理 → 选择已有教材”中勾选要发布的教材，展开“管理员发布已建立索引的教材”，填写英文教材标识和版本号后发布。
3. 平台应仅监听 `127.0.0.1:8766`，再用 Tailscale Serve 公开给 Tailnet：

```bash
tailscale serve 8766
```

4. 在 Tailscale 管理后台仅允许三位成员访问该主机的 HTTPS 服务。

通过 Tailscale Serve 远程打开主机页面时，发布接口只接受 `ANSWER_BOOK_SHARED_LIBRARY_PUBLISHERS` 中列出的 Tailscale 登录邮箱。直接在主机浏览器访问 `http://127.0.0.1:8766` 时可发布。示例：

```bash
export ANSWER_BOOK_SHARED_LIBRARY_PUBLISHERS="admin@example.com"
```

Tailscale Serve 会移除客户端伪造的身份请求头；不要把平台直接绑定到局域网或公网地址。

## 客户端配置

1. 每位用户本机安装并启动一份平台和 Tailscale。
2. 打开本机平台的“教材管理”，填写教材库主机的 Tailscale HTTPS 地址，例如 `https://textbook-host.example.ts.net`，点击“连接教材库”。
3. 点击“下载到本机”。程序会在本机后端完成目录读取、下载、SHA-256 校验、解压和索引安装。
4. 下载完成后，在本机已有教材列表中选择该教材创建任务。

浏览器不会直接跨域访问教材库；所有远程请求均由本机后端发起，所以 Sites 前端壳不需要保存教材库凭据或处理 CORS。

## 版本规则

- 教材标识和版本号只允许小写字母、数字、点、下划线、连字符。
- 已发布的版本不可覆盖。内容变更必须使用新版本号。
- 若客户端已有同名版本但哈希不同，程序会拒绝覆盖，避免教材和索引不一致。
- 包内保留 MinerU 源 ZIP、图片资源和索引缓存；安装时会把索引中的图片绝对路径重定向到客户端自己的教材资源缓存。
