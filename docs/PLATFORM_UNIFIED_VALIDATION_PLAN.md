# 平台统一验证方案

> 基线版本：`8.26-vnext.r3.1`  
> 范围：真题解析、题目生成、共享用户流程、质量与成本  
> 原则：测试用于发现通用设计缺口，不为单题写特判。

## 1. 验证目标

平台最终需要同时满足：

1. **稳定**：任务可创建、运行、恢复、取消和导出，部分失败不扩散。
2. **质量高**：题目、答案、解析、教材依据、公式和图件一致，高风险错误不得进入正式交付。
3. **体验合理**：用户能看懂进度、状态、失败范围和下一步，刷新或离开不丢任务。
4. **通用**：新题型、新学科、新教材和新图像不依赖样例 ID、题目文案或固定答案。
5. **成本可控**：每次请求可归因，无效重试可见，恢复运行不重做已完成的高成本阶段。

## 2. 统一硬门禁

以下任一项出现，都不得通过平均分掩盖：

- 漏题、重题、错序、题答错绑、原图或题图错绑。
- 高风险科学结论、数值、单位或唯一答案错误被标为正式版。
- 公式、化学式、标准态、晶体学索引等专业表达被文本化、损坏或泄漏裸 LaTeX。
- 生成题直接复制原题表层，或同套题在情境、未知量、方法和认知操作上高度重复。
- 题目条件不足、选项不可判定、作图缺少必要数据，却仍进入正式导出。
- 运行中、已取消、已超时或待复核任务在界面中显示为无风险完成。
- 刷新、重连或局部重生导致重复付费请求或覆盖已确认内容。

## 3. 测试轨道

### T：真题解析

- T1 文本单题：题目抽取、教材检索、证据绑定、答案和 DOCX。
- T2 原图理解：原图与题号绑定、真正视觉调用、文字答案同源。
- T3 专业作图：确定性 schema、程序图、标签和图文一致。
- T4 多题型集成：选择、填空、简答、计算、作图的局部失败隔离。
- T5 长整卷：长文、多图、多公式和跨教材时的累积退化。
- T6 恢复与交付：指纹一致复用、单题重算、formal/review_candidate/blocked 分层。

### G：题目生成

- G1 纯知识点：仅给名称生成蓝图和题目。
- G2 知识内容：粘贴教材原文，验证范围抽取、覆盖和非复制性。
- G3 按题出题：根据用户题目生成平行题、定向题和结构变式。
- G4 多题变式：父蓝图与 2–3 道变式的身份、难度和编辑隔离。
- G5 混合输入：图片、PDF、Word、TXT/Markdown 与文字混合时的范围恢复。
- G6 专业内容：计算题、化学/热力学符号、表格、必要题图与可作答性。
- G7 集合质量：题型/难度数量、来源覆盖、表层复制、集合多样性和稳定 ID。
- G8 局部失败：批次少题、重号、非法序号、单题超时与局部补生。
- G9 编辑与导出：单题编辑、重生、撤销、选中导出和正式 Word 门禁。

### U：用户旅程

- U1 提交和去重：立即显示已创建/排队，重复点击不创建重复任务。
- U2 进度：阶段、当前题、完成数、耗时和心跳真实。
- U3 离开和返回：刷新、关闭页面或重启服务后可继续查看。
- U4 取消和迟到响应：取消后的模型返回不得覆盖取消状态。
- U5 风险感知：正式版、待复核版和失败范围必须可见且易懂。

### C：成本与运行

- C1 逐请求记录文本/视觉/生图、token、耗时、usage 缺失和结果。
- C2 区分有效生成、程序触发的修复、外部失败和可避免浪费。
- C3 按成功题、正式文档和整个任务报告成本；无合同价格时只报用量。

## 4. 执行阶段

1. **P0 离线基线**：全量测试、类型/静态检查、公式链、导出契约和历史反例回放；0 次远程调用。
2. **P1 题目生成小额真实验证**：纯知识点、教材内容、原题变式各 1 组，每组 2–3 题。
3. **P2 跨流程小整体**：真题解析与题目生成各 1 个混合任务，验证并发、恢复和任务中心。
4. **P3 长任务与故障注入**：整卷、长教材、超时、取消、重启、局部失败和选中导出。
5. **P4 盲测与发布决策**：使用未参与开发的新题、新教材和独立人工评审。

## 5. 小额真实调用停止条件

- 同一协议错误或同一目标超时连续 2 次。
- 同一题局部补生超过 2 次，或同一图修复超过 1 次。
- 已发现高风险科学错误，但无可机器验证的修复。
- 正确性审查、用户可见内容与最终状态不一致。
- 请求数或耗时超过本批预算，先归因，不自动扩大。

## 6. 当前结论边界

- 真题解析已有单题、视觉、专业作图和五题型集成的真实证据；长整卷和完整用户旅程仍待验证。
- 题目生成有较广的自动化契约覆盖，但当前工作区没有任何可复核的真实生成历史，不能做发布结论。
- 下一个付费阶段必须优先补题目生成，而不是继续扩大已多次验证的单题解析。
