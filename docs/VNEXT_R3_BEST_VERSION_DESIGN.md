# VNext-R3 通用学科平台最佳融合版设计与验证

> 版本：`8.26-vnext.r3`  
> 定位：独立新候选版，不覆盖线上版、VNext.1 或 VNext-R2  
> 原则：真实题仅用于暴露通用缺陷，不将单题答案或样例规则写入核心流程

## 1. 结论

R3 以 R2 的本地优化能力栈为主体，保留 VNext.1 在候选答案保留、产物可读性和容错方面的优势，再修复两版共有的质量分层不清、图片角色混淆和数值错误漏检问题。

当前本地证据和 P2-02/P2-04/P2-05 小额真实模型回归支持 R3 作为下一轮 A/B 的首选候选版；P2-02 因服务商 SSL EOF 未完成科学答案验证，P2-05 仍检出模型计算错误，因此不宣称它已经在所有模型输出质量上胜出。

## 2. 五层通用架构

1. **核心编排层**：仅负责题目结构、调度、缓存、有界重试、产物生命周期和分层交付，不包含任何学科答案。
2. **通用契约层**：区分原题图与答案作图，检查作答覆盖、公式引用、算术一致性、图规格完整性、Word 和渲染产物。
3. **学科能力层**：材料学、物理、化学等专业语义只能通过可插拔 capability pack 贡献；XRD 消光和峰位规则已限定在 `materials.figures` 内。
4. **模型判断层**：处理开放性解析、图像理解与高风险学科复核；模型意见可触发一次有界修复，但不能冒充机器事实。
5. **交付与观测层**：记录每阶段耗时、请求次数、token/图像调用和重试链；明确输出正式版、待复核候选版或阻断。

## 3. 关键修复与验证目的

| 模块 | 用户可感知变化 | 程序/风险变化 | 验证什么 |
|---|---|---|---|
| 识图与作图意图 | 阅读题保留原图，不再无故重画 | “示意图”名词不再当成作图命令；旧 checkpoint 的冲突标志会被题干客观事实校正 | 碳相图历史任务以及数学、生物、物理原图反例 |
| 专业图规格 | XRD 不再出现两张互相矛盾的图，峰标签和线型可见 | 确定性能力规格优先；`hkl/label`、`dashed/--` 等同义字段归一化；相对峰位不再冒充绝对 `2θ` | 程序规格检查、渲染回归、P2-04 保存产物重放 |
| 候选图生命周期 | 最终 Word 只引用当前有效图 | 已失败、被取代或被剪枝的模型图及其图注会移出 fragment；原题图始终保留 | VNext.1 XRD 残留错图故障模式 |
| 计算一致性 | 减少“推导看似完整但算数错” | LaTeX 单位不再遮蔽数字表达式；通用安全求值器可检出任意学科的加减乘除和结果矛盾 | P2-05 保存公式检出 `-2088.6 != -2257`，并以路程、质量等跨学科公式作反例 |
| 结构自修 | 模型已写的解析不再因组装漏块而丢失 | `missing_analysis` 只能从保留的模型 draft 恢复，不允许程序编造新内容 | P2-05 和 V3 重复的同一程序缺陷 |
| 分层交付 | 有价值的答案不再因一项存疑而整份消失，同时不会被误当正式版 | 交付可用性与正式验收拆分；未解决的内容一致性或模型学科分歧输出 `review_candidate` | P2-02 错误修复无法机检时不再正式通过；P2-05 不再无 Word |
| 恢复与图件复用 | 断点恢复不再重复等待同一张已验证备用图 | 成功备用图会淘汰失败主图；提示词、模型、尺寸和图片完整性一致时复用，避免重复付费 | P2-05 首跑暴露生命周期阻塞，修复后恢复成功；新增无付费调用回归测试 |

## 4. 交付等级

- `formal`：产物完整，确定性门禁通过，无未解决学科/视觉建议。
- `review_candidate`：Word 可阅读，但内容、学科复核或视觉语义仍有存疑。同时产生 `answer_book_review_candidate.docx`、`question_review.docx` 和 `delivery_status.json`。
- `blocked`：没有可用答案、必需图丢失/损坏、Word 未生成或渲染产物损坏等客观交付失败。

## 5. 模型成本和耗时策略

- 确定性抽取、算术校验、能力规格生成和候选图清理不调用模型。
- 高风险正确性复核只选择计算、作图和结论—理由题，限制候选数、batch 数和修复轮数。
- 相同输入指纹优先复用选择性复核和视觉 QA 结果。
- 生图备用产物仅在提示词、模型、尺寸和图片完整性一致时复用；不一致则重新生成，避免错误缓存和重复付费两种风险。
- 确定性专业图可用时不再请求开放性绘图候选，减少图像模型和视觉修复轮数。
- `model_usage_report` 继续记录请求次数、类型、模型、token/图像用量、重试链和阶段耗时；最终择优时必须同时比较质量、完成率、增量耗时与增量成本。

## 6. 本地验证

- 全量测试：`908 passed, 7 skipped, 1 deselected`。跳过项均因独立副本中不包含历史 `practice_jobs` 样本，不是新失败。
- 完整质量门禁：`py_compile`、版本一致性、公式 OMML、项目完整性、`ruff`、`mypy` 全部通过，全库覆盖率 `63%`。
- 保存真实任务离线重放：识图/作图角色、P2-04 XRD 能力路由、P2-05 数值矛盾检测均通过。
- 小额真实模型验证：P2-02、P2-04、P2-05；详细调用、耗时、成本下限和剩余风险见 `VNEXT_R3_SMALL_REAL_MODEL_VALIDATION.md`。未开展全量/整卷付费矩阵。

## 7. 下一轮小额真实模型复测

先用同一份 provider/model 配置、同一份教材和同一套题目对 VNext.1、R2、R3 做小额三方对比；每个任务仅跑一次，不自动扩大。

1. P2-01 电子衍射：验证通用作图链和材料能力包的边界。
2. P2-02 热力学计算：验证模型科学错误未被修复时只能交付待复核版，不得正式通过。
3. P2-03 带轴衍射：验证程序专业图质量和无额外模型成本。
4. P2-04 XRD：验证单一有效规格、候选图清理、视觉 QA 与 Word 引用一致。
5. P2-05 综合题：验证单题失败不拖垮整卷、数值矛盾阻止正式版、已有 analysis 可确定性恢复。
6. V3 识图题：验证原图保留、不重画，并比较图像理解对最终答案的真实贡献。

每次保留：原题 DOCX/PDF/图片、教材文件、配置快照、`structured_exam.json`、`answer_fragments.json`、全部 audit/review/figure 中间件、最终 Word/PDF、`final_acceptance_report.json`、`delivery_status.json`、`model_usage_report` 与阶段耗时。
