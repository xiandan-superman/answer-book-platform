# Word 格式审查与修改（独立原型）

本目录是独立试用程序，未接入现有解析或生题流程。它按项目中的《真题答案与讲义格式标准》检查并修改 `.docx` 文件。

## 功能

- 两套独立标准：真题答案、讲义。
- 通过标准卡选择任务类型；点击“查看并配置完整规则”后，只进入当前所选标准的详情页。
- 主任务页不再重复展示配置区；页面、字体、字号、段落、标题层级、图表、页眉页脚等设置全部集中在标准详情页。
- 标准详情页默认是易读的只读规则；点击单项“修改”后，只有该行进入编辑状态，并显示“保存 / 取消”。
- 保存时选择“仅用于本次任务”或“设为永久默认”。
- 标准配置随首页一次返回，不再让主页面等待额外配置请求。
- 页眉文字在当前标准的详情页填写，可留空。
- “先审查，再确认修改”：先显示问题和修改意见，用户确认后才生成文件。
- “直接审查并修改”：审查完成后直接生成修改文件，同时显示原始问题清单。
- 自动处理页面、主要段落样式、页眉、页码、公式默认字体、独立图片段落和固定表格行高。
- 无法可靠判定内容角色的非标准样式只提示人工确认，不根据文字猜测硬改。

## 启动

macOS 可直接双击 `start_word_format_reviewer.command`，程序会自动打开浏览器。

也可以在项目根目录执行：

```bash
python3 -m standalone_word_format_reviewer.server --port 8788
```

浏览器打开 `http://127.0.0.1:8788`。

上传文件只写入系统临时目录，程序每次启动时清理超过 24 小时的旧任务。原文件不会被覆盖，下载的是新生成的 `.docx`。

## 当前边界

- 这是格式工具，不审查答案正确性、知识内容、题号逻辑或语言质量。
- 不会把图片公式或普通文字公式自动转换成 Word 公式，只会提示人工确认。
- 不重绘或缩放原图，不改写公式内容。
- 仅处理普通页眉；首页专用页眉、奇偶页不同页眉若启用，暂不单独改写。
